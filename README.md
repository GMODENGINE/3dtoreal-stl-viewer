# 3DtoReal STL Viewer

Открытый исходный код просмотрщика 3D-моделей страницы [3dtoreal.ru/stlviewer](https://3dtoreal.ru/stlviewer).

## Возможности

- локальное открытие STL, OBJ, GLB и 3MF;
- локальное преобразование STEP/STP в сетку;
- три уровня качества импорта STEP: черновое, стандартное и точное;
- размеры, площадь, объём и диагностика геометрии;
- оценка материала и стоимости FDM-печати;
- отправка исходной модели вместе с заявкой.

Файлы моделей обрабатываются в браузере и передаются на сервер только после явного подтверждения пользователя при оформлении заказа.

## Использование

Готовый встраиваемый виджет находится в `stl-viewer-widget.html`. Он использует ES-модули и должен открываться через HTTP(S), а не через `file://`.

## Зависимости

- [Three.js](https://threejs.org/) 0.184.0 — MIT;
- [meshStep](https://github.com/CNCKitchen/meshStep) 0.1.1 — AGPL-3.0-only.

meshStep загружается без изменений из зафиксированной версии на jsDelivr. Исходный код этой версии доступен в репозитории meshStep и в пакете `meshstep@0.1.1`.
